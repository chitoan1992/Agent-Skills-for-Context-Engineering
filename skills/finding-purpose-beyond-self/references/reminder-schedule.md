# Reminder Schedule (Lịch nhắc nhở)

Turns the review cadence into real, repeating calendar reminders. Generated by
`scripts/generate_reminders.py` as a standard `.ics` you import into Google
Calendar, Apple Calendar, or Outlook. Reminders use floating local time, so
they fire correctly wherever you are.

## The five recurring reminders

| # | Reminder | Default time | Repeat | Duration |
|---|---|---|---|---|
| 1 | Two-line journal (whom did I serve? how did it feel?) | 21:00 | every day | 2 min |
| 2 | Re-read the week's journal — just notice | Sunday 20:00 | weekly | 5 min |
| 3 | Score the cycle /25 → Scale / Refine / Pivot | 20:00 | every 30 days | 30 min |
| 4 | Convergence check — read the last 3 hypotheses | 19:00 | every 90 days | 1 hr |
| 5 | Yearly arc statement | 10:00 | yearly | half day |

The daily reminder is the engine; the others are evaluation checkpoints that
keep the plan improving instead of going stale.

## Example concrete schedule (cycle day 1 = 2026-06-16)

- **Daily journal**: every day 21:00, starting Tue 16 Jun 2026
- **Weekly notice**: every Sunday 20:00, first Sun 21 Jun 2026
- **Cycle review**: Wed 15 Jul 2026, then 14 Aug, 13 Sep, 13 Oct … (every 30 days)
- **Quarterly check**: Sun 13 Sep 2026, then ~12 Dec 2026 … (every 90 days)
- **Yearly arc**: Tue 15 Jun 2027, then yearly

## Generate your own

```bash
# Defaults to tomorrow, English:
python scripts/generate_reminders.py

# Pick a start date, journal time, and language:
python scripts/generate_reminders.py \
    --start 2026-06-16 --journal-time 21:00 --lang vi \
    --output purpose-reminders.ics
```

Then import `purpose-reminders.ics`:

- **Google Calendar**: Settings → Import & export → Import → choose the file
- **Apple Calendar**: File → Import → choose the file
- **Outlook**: File → Open & Export → Import/Export → import an iCalendar file

## Why a calendar file (not an in-app loop)

A `.ics` lives on your own devices and keeps firing for years, independent of
any chat session or service staying online. That durability is the whole point
of a reminder loop meant to outlast a single 30-day cycle. Adjust the times
freely after import — the schedule is a scaffold, not a rule.
